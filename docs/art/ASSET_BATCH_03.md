# Production Asset Batch 3: Loomington rooms and collection

Part of the [Style Bible](STYLE_BIBLE.md). Batch revision: **1**. Style suffix version: **v1**. Hemp guards version: **v1**. Written by `tools/build_asset_batch_03.py`, which copies the suffix and guards word for word from section 21 of the bible. Never edit this file by hand.

**17 images in 6 rounds.** They build Loomington, the night city of mills and the second world: seven new rooms with their workers (the eighth, the Spice Kitchen Bistro, is your v2 floor 08), back walls for all eight rooms, the city background in layers, Mayor Thyme, the four Loomington herbs, the first three hybrids and the seven heirloom icons still missing.

The Loomington managers and the moving sheets for these workers are Batch 4. Rooms follow the recipe of the Batch 1 ropewalk (prompt 15): props and two workers in one row, the tap target in the middle, the manager's spot at the right end. Managers draw at 96×96 since Batch 2 round 8, so Mayor Thyme does too.

Names follow the game design document (version 0.3). Each prompt describes a look, not a name, so a rename does not spoil an image.

## How to do it on your phone

The easiest way is the **master file**: attach `Sprout_Tower_Batch3_Master.md` and `Sprout_Tower_Batch3_References.zip` (both in the project files, `art/batch03/master/`) to one new ChatGPT chat and type **next** between images. If the chat gets full, start a new chat with the same two files and type **start at image N**. The rounds below are the same images, one prompt at a time, if you prefer that.

1. Each round is **one new ChatGPT chat**.
2. At the start of a round, **attach that round's two reference images** (listed below) and paste the round's first prompt in the same message.
3. Then paste the round's other prompts **one at a time, in the same chat**. **Rounds 4 and 6** need one or two more pictures, named in bold at the top of the prompt.
4. Each prompt is one grey box. Copy the whole box, change nothing.
5. Upload the zip as well as the picture. If ChatGPT makes no zip, the picture alone is fine.
6. Save each picture as **PNG, original size**. No screenshots, no JPG, no cropping or resizing.
7. Upload the results in number order, or tell me which number each one is.
