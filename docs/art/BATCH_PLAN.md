# Art batch plan: from Batch 1 to a four-world launch

Part of the [Style Bible](STYLE_BIBLE.md). Owner: Art Director.

This page says which batch makes which art, so that nothing the launch needs is forgotten and nobody is asked for the same image twice. It follows the game design document, version 0.2, which plans **four worlds at launch**: Thymeford, Loomington, Papaya Cay and Mount Mitten. That version is still in re-check, so names are near-final. A renamed row changes a label in a prompt, not this plan.

## How the plan works

- A batch is 10 to 20 images that Lawson generates in ChatGPT from a prompt file like [ASSET_BATCH_01.md](ASSET_BATCH_01.md).
- **Only Batch 1 is written.** Each later batch becomes a prompt file once the batch before it has been checked, because the results show what to ask for next. The image counts below are estimates.
- The order follows what a player sees first.
- Every prompt carries the fixed style suffix v1 and, where hemp appears, a hemp guard. Nothing on this page changes the look.
- Each batch keeps a few places free for redos of the batch before it.

**Open point: managers.** On 2026-11-25 Lawson chose one fixed manager per floor instead of manager cards for any floor. The Game Designer is revising the manager list. Until that list is in, the manager images wait: prompt 18 in Batch 1 and the manager rows in Batches 2, 3 and 5.

### How the counts are made

| Asset | Images |
|---|---|
| A new room: tap target, props, two workers, manager spot | 1 per room |
| Back walls | 1 per two rooms |
| Lead worker animation sheet (nine frames) | 1 per room |
| Second workers on short sheets (stand, blink, two work frames) | 1 per four or five workers |
| Managers in floor-neutral poses | 1 per three to five managers |
| Plant cards | 1 per four or five cards |
| A world background in parallax layers | 2 per world |
| An icon set | 1 |

**The biggest block is the lead worker sheets:** 31 of the 103 images. Batch 1 prompts 8 to 10 are the first three sheets. If they come back clean, later sheets try two workers per image, which would save about 15 images.
