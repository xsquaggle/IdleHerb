# Art batch plan: from Batch 1 to a four-world launch

Part of the [Style Bible](STYLE_BIBLE.md). Owner: Art Director.

This page says which batch makes which art, so that nothing the launch needs is forgotten and nobody is asked for the same image twice. It follows the game design document, version 0.3, which plans **four worlds at launch**: Thymeford, Loomington, Papaya Cay and Mount Mitten. That version is still in re-check, so names are near-final. A renamed row changes a label in a prompt, not this plan.

## How the plan works

- A batch is 10 to 20 images that Lawson generates in ChatGPT from a prompt file like [ASSET_BATCH_01.md](ASSET_BATCH_01.md).
- **Batches 1 and 2 are written** ([ASSET_BATCH_02.md](ASSET_BATCH_02.md) since 2026-11-26). Each later batch becomes a prompt file once the batch before it has been checked, because the results show what to ask for next. The image counts below are estimates.
- The order follows what a player sees first.
- Every prompt carries the fixed style suffix v1 and, where hemp appears, a hemp guard. Nothing on this page changes the look.
- Each batch keeps a few places free for redos of the batch before it.

Each later world gets three manager sheets in its cast batch: floors 1 to 3, floors 4 to 6, and the two top floors. The manager rows below follow version 0.3.

### How the counts are made

| Asset | Images |
|---|---|
| A new room: tap target, props, two workers, manager spot | 1 per room |
| Back walls | 1 per two rooms |
| Lead worker animation sheet (nine frames) | 1 per room |
| Second workers on short sheets (stand, blink, two work frames) | 1 per four or five workers |
| Manager sheets, four poses each | 1 per two or three managers |
| Plant cards | 1 per four or five cards |
| A world background in parallax layers | 2 per world |
| An icon set | 1 |

**The biggest block is the lead worker sheets:** 31 of the 118 images. Batch 1 prompts 8 to 10, the first three sheets, came back clean: nine frames each, the same character in every frame, and a shared head with body layers. So from Batch 2 on, a worker sheet asks for two workers. That would save about 15 images. Batch 2 puts two workers on every sheet (prompt 10 is the first). If that fails, its fallback sentence splits a sheet in two, and the later batches go back to one worker per sheet. The tables for Batches 3 to 8 below still count one worker per sheet.
